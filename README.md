## 🏭 Supplier Quality Power BI & Python Analysis

Supplier quality analysis focused on identifying which vendors should be prioritized for corrective-action review based on recorded production downtime.

The project combines **Power BI, Python, Excel, and dimensional data modeling**.

The analysis explores:

- Supplier downtime
- Vendor deterioration
- Like-for-like vendor comparison
- Defect classification
- Plant performance
- Material performance
- Outlier detection
- Sensitivity analysis
- Corrective-action prioritization

### Dashboard Pages

- Executive Overview
- Vendor Analysis
- Defect Analysis

### Key Highlights

- **6,145 supplier-quality observations**
- **318 vendors**
- Downtime increased from **62,681 to 76,607 minutes**
- Overall increase: **+22.22%**
- Same-vendor increase: **+13.82%**
- Top five vendors accounted for approximately **41% of 2014 downtime**
- Rejected downtime increased by approximately **326.9%**
- Sensitivity testing showed that some supplier rankings were driven by extreme events

### Technologies

`Power BI` `Python` `Pandas` `NumPy` `Matplotlib` `Power Query` `DAX` `Excel`

🔗 **View Project:**  
[Supplier Quality Power BI Analysis](https://github.com/BinhPhan172/supplier-quality-powerbi-analysis)
